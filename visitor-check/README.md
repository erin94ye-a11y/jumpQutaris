# 访问环境与网络识别

极简白色页面，打开即自动记录基础访问，浏览器随后补充设备参数；密码保护的后台查看记录与 IP 网络标签。Node.js 24+，无须安装第三方运行依赖。

## 本机使用

### 界面语言

访客页和管理后台均以完整英文文案为默认和备用版本，自动按设备语言偏好匹配英文、中文、西班牙语、法语、德语或日语。其他语言回退英文。页首可以选择界面语言，手动选择会保存在当前浏览器；选择“Automatic (device language)”恢复自动匹配。禁用 JavaScript 时显示英文基础页面。

可用 `?lang=en` 临时打开纯英文预览（后台同样支持），也支持 `zh`、`es`、`fr`、`de`、`ja`。优先级为链接指定语言、浏览器中保存的手动选择、设备语言偏好、英文备用。切换界面不创建新的访问记录，不改变后台记录的真实设备语言列表。

在本目录运行 `npm start`。访客页为 http://127.0.0.1:4180/ ，后台为 http://127.0.0.1:4180/admin 。英文预览为 http://127.0.0.1:4180/?lang=en 。管理员本机密码在首次启动生成的 `data/local-credentials.json` 中。

打开访客首页就会保存 IP、请求时间、浏览器标识和请求语言，不需要点击同意，也不需要访客登录账号。JavaScript 运行后自动补充语言、时区、系统平台、屏幕尺寸等浏览器允许提供的参数。拒绝脚本、提前关闭或网络失败时，后台仍保留基础记录；扩展参数可能缺失。后台、脚本、样式请求不会额外创建记录。刷新访客首页会创建新记录；同一页面重试补充信息只更新原记录。

页面保留简短数据用途说明。没有精确定位、摄像头、麦克风权限请求，也不绕过浏览器隐私限制。机器人、链接预览和自动扫描也可能产生访问记录，访问量不等于真实人数。

## 启用 VPN / 网络类型识别

接口已接入 **ipapi.is**。该服务的 VPN、代理、移动运营商、数据中心等检测字段需要 API 密钥；未配置时后台明确显示“网络识别未启用”，不能进行实际检测。

1. 在 [ipapi.is](https://ipapi.is/) 获取适合用途的账户及 API 密钥。
2. 将 `.env.example` 复制为 `.env`，在本机文件内填写 `IPAPI_KEY`，不要把密钥发到聊天中或写入前端。
3. 在本目录重新运行 `npm start`。启动命令自动加载本目录 `.env`；也可通过托管平台环境变量注入。
4. 部署后用公网访问验证。127.0.0.1、私网或保留地址不向第三方查询，显示本地地址。

默认未配置密钥时，公网 IP 仍通过原有 ipwho.is 查询大致地理位置。配置密钥后由 ipapi.is 返回地区与网络信息；密钥只在服务器端发送，使用 HTTPS POST，避免放入查询 URL。缺失字段不会自动转成“否”。服务失败或限额时保留基础记录，不编造网络类型。

后台并列显示 VPN、代理、Tor、移动网络、数据中心的检测结果，这些标签可以同时成立。`未检出`表示该数据源没有标记，不代表保证不存在；`未知`表示缺失、未配置或查询失败。`ISP`只能提示网络归属互联网服务提供商，不能证明是家庭宽带，亦可能用于企业、热点或代理。移动设备、浏览器报告的 `4g`、移动运营商 IP 是不同概念，不能互相替代。

权威接口资料：[响应字段与 POST 接口](https://ipapi.is/developers.html)、[匿名响应变更](https://ipapi.is/changelog.html)、[使用条件](https://ipapi.is/terms.html)。免费账户当前仅适用于测试和开发，商业使用需选择相应方案；额度与条款以服务商最新说明为准。没有任何服务能保证识别全部 VPN、住宅代理或物理接入类型。

## 部署

将本目录作为独立 Node 应用部署，或使用附带 Dockerfile。不能使用纯静态托管：自动记录、数据库、密码登录和网络查询均需要后端。

| 变量 | 用途 |
| --- | --- |
| `NODE_ENV` | 正式部署设为 `production` |
| `ADMIN_PASSWORD` | 生产必填，至少 16 字符，建议 24 字符以上随机密码 |
| `PUBLIC_ORIGIN` | 生产必填的 HTTPS 源地址，例如 `https://check.example.com`，不带路径 |
| `IPAPI_KEY` | IP 情报服务密钥；留空时网络检测未启用 |
| `DATA_DIR` | 持久目录，默认 `data`；Docker 镜像内为 `/data`，需挂载持久卷 |
| `PORT` | 默认 4180 |
| `HOST` | 本机默认 `127.0.0.1`；生产默认 `0.0.0.0`；同机代理推荐 `127.0.0.1` |
| `TRUST_PROXY_HOPS` | 默认 0，仅使用连接 IP；按实际可信代理层数设置 |

同机 Nginx 单层 HTTPS 代理示例：

```nginx
location / {
    proxy_pass http://127.0.0.1:4180;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $remote_addr;
    proxy_set_header X-Forwarded-Proto https;
    client_max_body_size 16k;
}
```

此示例设置 `HOST=127.0.0.1`、`TRUST_PROXY_HOPS=1`，阻止外部直接访问应用端口。代理必须覆盖访客传入的转发头；多层代理不能照搬层数。正式上线需核对后台记录的公网 IP，避免检测的是代理服务器地址。

不要用通用静态服务器公开整个应用目录。原官网服务器已阻止访问该目录，重启原官网进程后生效。部署包不包含本机密码、`.env` 或数据库。Dockerfile 已提供，但未在此环境构建。

## 记录与访问保护

SQLite 持久保存，30 天到期；列表排除过期记录，启动及每分钟清理。管理员可以提前删除。备份保留期和磁盘加密由服务器管理员管理，数据文件没有应用层加密。

管理员会话有效期 8 小时，HttpOnly、SameSite=Strict，生产使用 Secure Cookie。退出或重启清除会话。登录、页面采集、参数更新均有限流。应用适合单实例使用；多实例需要共享数据库、会话和限流存储。

新记录明确标记“自动记录”，保存说明版本，不伪造同意状态。旧版同意记录保留原字段。参数补充通过仅针对当前记录的短时令牌、同源校验和输入白名单处理，不能读取或删除其他访客记录。

IP 在美国、语言 en-US、美国时区都只是环境线索，不能证明国籍、真实所在地或身份。后台不生成国籍概率。

## 测试

`npm test` 使用临时数据库与模拟情报响应。测试覆盖访问即记录、无脚本基础记录、同页重试不重复、异步查询不阻塞页面、不覆盖设备更新、不恢复已删除记录，以及登录、限流、过期、同源和目录隔离。部署后仍需验证 HTTPS、真实代理 IP、密钥有效性、服务额度和持久卷。
